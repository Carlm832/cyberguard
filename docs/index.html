FAQ

Frequently Asked Questions

Everything you need to know about CyberGuard, local inference, and our privacy guarantees.

Can I use CyberGuard on a mobile device?
Yes! While there is no native mobile app installer, the CyberGuard Cloud Web Platform is fully responsive and optimized for mobile devices (iPhone, iPad, Android smartphones, and tablets). Simply navigate to the web application in your mobile browser to scan phishing emails and consult ARIA on the go.
How does the offline rule engine protect my privacy?
CyberGuard processes all phishing heuristics, password evaluations, and certainty scoring entirely in local memory on your device. Your sensitive data is never saved on remote servers, logged to analytics platforms, or used to train third-party AI models.
Is it safe to test my real passwords in CyberGuard?
Yes. CyberGuard calculates entropy and pattern checks purely client-side. For breach verification, it uses mathematical k-anonymity: your password is SHA-1 hashed locally, and only the first 5 characters are sent to the Have I Been Pwned API. The API returns hundreds of matching hashes, and your client checks for a match locally. Your raw password is never transmitted.
Can I use ARIA without an active internet connection?
Yes! CyberGuard features a built-in deterministic fallback engine. When offline or without API keys, ARIA references the local knowledge base (R01-R10) to deliver precise, rule-grounded threat explanations and action steps without needing cloud AI.
What is a Certainty Factor (CF) and how is risk calculated?
Certainty Factors (CF) represent the statistical weight each rule contributes to a risk score (e.g. Credential Harvesting has a high CF of +0.25). The inference engine aggregates these weights and triggers compound rules (e.g. urgency + unknown sender) to produce an explainable threat rating: LOW (<0.40), MEDIUM (0.40-0.69), or HIGH (≥0.70).
